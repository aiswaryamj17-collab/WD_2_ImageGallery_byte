# Responsive Image Gallery (Task 2)

A clean, responsive image gallery built with HTML5 and CSS3 featuring an overlay lightbox viewer, smooth image transitions, next/previous navigation controls, and accessibility alt-text.

## Features
- **Responsive CSS Grid:** Automatically adapts and reorganizes columns based on different screen sizes.
- **Lightbox Overlay:** Full-screen pop-up view triggered when clicking any image thumbnail using CSS pseudo-classes.
- **Navigation Controls:** Built-in next, previous, and close buttons for a seamless user experience.
- **Accessibility:** Includes descriptive `alt` text and caption paragraphs for screen readers and users.

## Technologies Used
- **HTML5:** Semantic structure, layout markup, and anchor-based lightbox states.
- **CSS3:** Grid layout, flexbox, transitions, fixed positioning, and styling.
